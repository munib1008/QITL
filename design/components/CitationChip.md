# CitationChip

A visible, clickable citation anchor. Opens the evidence drawer or the canonical page of the source.

- Provide `children` (the canonical reference string, always LTR in `reference` mono), optional `kind` prefix, `href` or `onClick`.
- Quran: `Q <surah>:<ayah>`; Hadith: `<Collection> <canonical number>` plus numbering system on the detail page.
- Never invent a reference, even in demos — use a dash placeholder (`No. —`) labelled DEMO.
