# MapLegend

Permanent atlas legend: Verified point / Approximate region / Unknown location / Historical hypothesis (+ optional Approximate route). Always on screen while the map is; collapses to a button on mobile but keeps attribution visible.

- Provide `attribution` (required — the tile/data provider credit) and optional `items`, `title`.
- Approximate regions are hatched sage polygons; hypotheses are dotted brass outlines with no fill; unknown locations are a dashed "?" ring placed in a side list, not on the map.
- Never assign exact coordinates to an ambiguous scriptural location.
