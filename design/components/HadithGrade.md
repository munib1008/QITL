# HadithGrade

One grading of one narration by one named scholar, with its source. A narration can carry several — list them all; never collapse disagreement into a single badge.

- Provide `grade`, `grader`, `source`; `authentic` when the grade is sahih/hasan (renders the hadith mark); `varies` when other recorded gradings differ.
- No grade recorded → renders "Grade not recorded" with the unknown mark. Never infer a grade from the collection name.
