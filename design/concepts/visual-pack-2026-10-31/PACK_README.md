# QITL visual asset pack

Contains logo/banner concepts, 16 story covers, 12 UI icons, 5 wide ambient illustrations and 5 genuinely animated GIF loops.

**Usage:** PNG covers go on story cards and event pages; icons go in navigation; GIFs are optional preview animations in Kids Mode. Prefer responsive PNG/WebP and CSS/Lottie motion in production.

**Important:** These are AI-generated *concept illustrations*, not authenticated visual reconstructions. Do not treat embedded text as canonical Arabic or Quran text. Avoid depicting prophets and the unseen. The garden/fire illustrations are metaphorical motifs, NOT literal depictions of Jannah/Jahannam. Have editorial staff review all assets prior to publication. The different dimensions are specified in manifest.json.

**Coverage:** This is a starter collection for the named key stories and app features discussed. It does not yet illustrate all 25 prophets or every Quranic event.
